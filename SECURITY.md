# Security Policy

BeetstreamNext is a self-hosted project maintained by me in my free time (which I don't have a lot of).

Security reports are welcome and appreciated.

## Supported Versions

Only the current pre-release version is supported

| Version | Supported          |
|---------| ------------------ |
| 1.9.0   | :white_check_mark: |
| 1.8.5   | :white_check_mark: |
| 1.8.0   | :white_check_mark: |
| < 1.8.0 | :x:                |

## Reporting a Vulnerability

Please report security issues privately, do **not** open a public GitHub issue or pull request, and do **not** disclose the issue publicly until it is fixed.

Use GitHub's private vulnerability reporting: https://github.com/FlorentLM/BeetstreamNext/security/advisories/new (repository Security tab -> Report a vulnerability). Only I can see it.

Or you can email me at 25004801+FlorentLM@users.noreply.github.com

Please include a short description, which OS you're using, and steps to reproduce.
Again, this is a single-person project I do on my spare time, so please bare with me.
